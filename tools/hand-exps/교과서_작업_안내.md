# 교과서 실험 → 손으로 탐구 실험실 작업 안내 (로컬 세션용)

## 파일 두는 곳
- 교과서 PDF: 저장소 안 `_textbooks/` 폴더 (`.gitignore` 에 들어 있어 커밋되지 않습니다)
- 이름 규칙(권장): `_textbooks/중1_출판사.pdf`, `_textbooks/중2_출판사.pdf`, `_textbooks/중3_출판사.pdf`
  (한 학년에 여러 권이면 `중1_출판사_1.pdf` 처럼 번호)

## 원칙 (선생님이 정한 것)
1. **실험 과정은 교과서에 실린 실험 과정 그대로** 씁니다. 이지메이커·사이언스큐브 같은 업체 절차가 아닙니다.
   교과서 문장을 손으로 탐구 실험실 형식(단계별 한 문장)에 맞게 다듬되, 순서·도구·양·조건은 교과서를 따릅니다.
2. **과학 원리를 데이터로 배우는 실험 위주**로 고릅니다. 관찰만 하는 활동, 만들기 활동은 뺍니다.
   가로축–세로축 관계가 나오거나 조건별로 견줄 수 있는 실험이어야 합니다.
3. 손으로 탐구 실험실의 가장 큰 목적은 **모둠별 데이터를 반 전체가 함께 보는 것**입니다.
   그래서 실험마다 데이터 수집 형태를 정합니다.
   - `dataSpec`: 가로축·세로축 열(라벨·단위), 줄 수, 그래프 모양. 계산으로만 얻는 열은 `calc:true`
   - `pool.assign`: 모둠마다 맡을 값(가로축 값 또는 조건), `per`(모둠당 개수)
     - 직선 관계 4~5개, 곡선·봉우리 6~8개, 한 점에 오래 걸리거나 재료가 드는 실험 3개, 조건형 1~2개
     - 값은 모둠마다 범위 전체에 흩어지고 모둠끼리 엇갈리게(1·4·7·10·13 / 2·5·8·11·14 …)
   - `analysis`: 판정은 반대 방향·변화 없음을 먼저 거른 뒤 성공 판정(`pass:true`)
4. 이미 있는 실험(lab-data.js 76건)과 겹치면 새로 만들지 말고 **기존 실험의 과정을 교과서 과정으로 바꿉니다**.
   `textbook` 칸에 「출판사 학년 쪽」을 적습니다.

## 넣는 방법
- 센서 없이 하는 실험: `tools/hand-exps/new_exps_*.json` 에 한 건씩 추가 → `python3 tools/hand-exps/build.py`
  (lab-data.js · hand-data.js · demo-data.js 의 표시 구간은 손으로 고치지 않습니다)
- 확인: 모든 실험이 제 예시 자료로 성공 판정, 뒤집은 자료로는 실패 / 브라우저에서 inquiry.html 로 끝까지 진행
- 배포 전에 `python3 bump_ver.py .`
