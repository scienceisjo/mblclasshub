연수 시연용 예시 파일

코드 없이(간편 모드) 실험한 뒤, 선생님이 걷어서 반 전체를 합쳐 보는 흐름을 그대로 보여 드리기 위한 파일들입니다. 값은 보일의 법칙(60 mL 주사기, 30 mL에서 마개 잠금) 예시이며, 모둠마다 부피 눈금을 어긋나게 나눠 맡아 5점씩 잰 상황입니다 — 합치면 12~60 mL가 거의 빈틈없이 채워지며 반비례 곡선이 완성됩니다. 압력 × 부피는 29.6~30.5로 일정합니다.

① 학생 작업 파일 4개 — 「제출된 보고서 합치기」에 끌어다 놓기

  1. 1모둠 (12·22·32·42·52 mL)
  2. 2모둠 (14·24·34·44·54 mL)
  3. 3모둠 (17·27·37·47·57 mL)
  4. 4모둠 (19·29·39·49·60 mL)

교사용 화면 → 파일로 하는 수업 → 제출된 보고서 합치기에 네 파일을 한꺼번에 끌어다 놓으면 모둠별 표·그래프·보고서가 정리되고, 대시보드의 모둠 겹친 그래프 블록으로 하나의 그래프가 됩니다.

② 수합 시트 CSV — 「데이터 붙여넣고 분석하기」에 붙여넣기

수합시트_주사기압력_모둠열.csv

첫 열이 모둠 이름입니다. 엑셀에서 열어 전체 복사한 뒤 학생용 화면 → 데이터 붙여넣고 분석하기에 붙여넣으면 “첫 열이 모둠 이름으로 보입니다 — 갈라 담을까요?”가 뜨고, 모둠별 기울기 비교와 반 전체 그래프까지 한 번에 나옵니다.

시연 순서 제안

  1. 학생 화면에서 간편 모드로 실험 하나를 잠깐 보여 주고, [지금까지 한 것 내려받기]로 작업 파일이 생기는 것을 보여 줍니다.
  2. “이 파일을 네 모둠에게서 걷었다고 하겠습니다” 하고 위 ①의 네 파일을 교사 화면에 끌어다 놓습니다.
  3. 모둠별로는 다섯 점짜리 조각이지만, 합치는 순간 12~60 mL 반비례 곡선이 빈틈없이 완성되는 것을 보여 줍니다.
  4. 구글 시트로 걷는 반이라면 ②의 CSV 방식이 같은 자리라고 안내합니다.
